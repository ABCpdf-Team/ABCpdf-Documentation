# RefAtom Constructor

Construct a RefAtom.

## Syntax

*C#*

[`RefAtom`](../index.md)`()`  
[`RefAtom`](../index.md)`(IndirectObject value)`

## Params

| Name | Description |
| :---: | --- |
| value | The initial IndirectObject that the Atom should point to. |

## Notes

Create a RefAtom.

If an [IndirectObject](../../../6-abcpdf.objects/1-indirectobject/index.md) is not specified the default of the null object at entry zero will be used.
