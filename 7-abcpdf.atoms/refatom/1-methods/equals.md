# Equals Function

Test whether the two RefAtoms are the same

## Syntax

*C#*

`bool Equals(`[`RefAtom`](../index.md)` other)`

## Params

| Name | Description |
| :---: | --- |
| other | The RefAtom to test against. |

## Notes

Test whether the two RefAtoms are the same.

Two RefAtoms are judged to be equal if their [ID](../2-properties/1-id.md) and [Gen](../2-properties/2-gen.md) properties are equal.
