# Equals Function

Test whether the two NullAtoms are the same

## Syntax

*C#*

`bool Equals(`[`NullAtom`](../index.md)` other)`

## Params

| Name | Description |
| :---: | --- |
| other | The NullAtom to test against. |

## Notes

Test whether the two NullAtoms are the same.

NullAtoms are always equal to each other.
