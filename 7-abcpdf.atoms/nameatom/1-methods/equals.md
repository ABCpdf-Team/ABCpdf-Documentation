# Equals Function

Test whether the two NameAtoms are the same

## Syntax

*C#*

`bool Equals(`[`NameAtom`](../index.md)` other)`

## Params

| Name | Description |
| :---: | --- |
| other | The NameAtom to test against. |

## Notes

Test whether the two NameAtoms are the same.

Two NameAtoms are judged to be equal if their [Text](../2-properties/text.md) is equal.
