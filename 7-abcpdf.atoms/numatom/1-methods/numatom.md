# NumAtom Constructor

Construct a NumAtom.

## Syntax

*C#*

[`NumAtom`](../index.md)`()`  
[`NumAtom`](../index.md)`(int value)`  
[`NumAtom`](../index.md)`(long value)`  
[`NumAtom`](../index.md)`(double value)`

## Params

| Name | Description |
| :---: | --- |
| value | The initial integer or floating point value that the Atom should adopt. |

## Notes

Create a NumAtom.

If a value is not specified the default of zero will be used.
