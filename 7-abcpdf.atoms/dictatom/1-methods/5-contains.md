# Contains Function

Determines whether the dictionary contains an element with a specific name.

## Syntax

```csharp
bool Contains(string key)
```

## Params

| Name | Description |
| :---: | --- |
| key | The element to locate in the dictionary. |
| return | True if the name is found, otherwise false. |

## Notes

Determines whether the dictionary contains an element with a specific name.
