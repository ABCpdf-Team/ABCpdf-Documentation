# IccGray Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | "standard" | No | The path to the default Gray ICC color profile. |

## Notes

A path to the default Gray ICC color profile.

The principles behind this property are the same as [IccCmyk](icccmyk.md) but for colors in device Gray.

See the [IccCmyk](icccmyk.md) property.
