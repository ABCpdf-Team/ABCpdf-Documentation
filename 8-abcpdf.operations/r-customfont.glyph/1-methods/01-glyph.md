# Glyph Function

Create a [CustomFont](../../r-customfont/index.md) [Glyph](../index.md).

## Syntax

*C#*

[`Glyph`](../index.md)`(char c, int unicode, XRect bbox, FormXObject image)`

## Params

| [Name](../2-properties/05-name.md) | Description |
| :---: | --- |
| c | The character to be used to reference this glyph. |
| unicode | The [Unicode](../2-properties/02-unicode.md) value. |
| bbox | The bounding box in points. |
| image | The visual appearance. |
