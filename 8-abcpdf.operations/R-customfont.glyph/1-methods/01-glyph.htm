Glyph Function    

Create a CustomFont Glyph.

 

    

Syntax		  

[C#]
Glyph(char c, int unicode, XRect bbox, FormXObject image)

 

    

Params		  
Name Description
c The character to be used to reference this glyph.
unicode The Unicode value.
bbox The bounding box in points.
image The visual appearance.

 

    

Notes		  
Create a CustomFont Glyph.

 

    

Example		  
None.
