# ExtractStructure Function

Extract the structure in an HTML-like format that can be displayed in a browser.

## Syntax

```csharp
StringBuilder ExtractStructure(bool noIDs = false)
```

## Params

| Name | Description |
| :---: | --- |
| noIDs | Whether to leave out the ObjID attributes. |
| return | The structure HTML. |

## Notes

Extract the structure in an HTML-like format that can be displayed in a browser.
