# Structure Function

Create a new [Structure](../index.md) based on the content in a doc.

## Syntax

*C#*

[`Structure`](../index.md)`(Doc doc)`

## Params

| Name | Description |
| :---: | --- |
| doc | The doc to read. |

## Notes

Create a new [Structure](../index.md) based on the content in a doc.

After creating this object you should check the [Root](../2-properties/02-root.md) property to determine if a document structure has been found.
