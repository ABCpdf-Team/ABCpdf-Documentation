# CTM Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`XTransform`](../../../5-abcpdf/xtransform/index.md) | null | Yes | The Current Transformation Matrix (CTM). |

## Notes

The Current Transformation Matrix (CTM).

This is used to map user coordinates - the values in the content stream - to device coordinates - positions on the page.
