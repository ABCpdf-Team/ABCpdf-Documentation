# Contents Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`ArrayAtom`](../../../7-abcpdf.atoms/arrayatom/index.md) | n/a | Yes | An array containing the Atoms in the PDF content stream. |

## Notes

An array containing the Atoms in the PDF content stream.

This property is populated by the [LoadContents](../1-methods/02-loadcontents.md), [LoadMCIDs](../1-methods/03-loadmcids.md) and [LoadText](../1-methods/04-loadtext.md) methods.
