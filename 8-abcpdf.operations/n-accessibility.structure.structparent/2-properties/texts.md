# Texts Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `SortedDictionary<int, string>` | n/a | Yes | A mapping between MCIDs in the content stream, and the text they contain. |

## Notes

A mapping between MCIDs in the content stream, and the text they contain.

This property is populated by the [LoadText](../1-methods/04-loadtext.md) method.
