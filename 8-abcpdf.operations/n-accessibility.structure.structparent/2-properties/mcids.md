# MCIDs Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `SortedDictionary<int, `[`StructParent.Range`](../../n-accessibility.structure.structparent.range/index.md)`>` | n/a | Yes | A mapping between MCIDs in the content stream, and their start and end indices in the Contents array. |

## Notes

A mapping between MCIDs in the content stream, and their start and end indices in the Contents array.

This property is populated by the [LoadMCIDs](../1-methods/03-loadmcids.md) method.
