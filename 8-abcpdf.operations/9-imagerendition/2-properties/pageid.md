# PageID Property

| Type | Default | Read Only | Description |
| --- | --- | --- | --- |
| `int` | n/a | Yes | The ID of the Page on which the image is placed. |

## Notes

The ID of the Page on which the image is placed.

You can assign this ID to the [Doc.Page](../../../5-abcpdf/doc/2-properties/page.md) or you can use it with the [ObjectSoup](../../../6-abcpdf.objects/2-objectsoup/index.md) to retrieve a [Page](../../../6-abcpdf.objects/page/index.md) object.
