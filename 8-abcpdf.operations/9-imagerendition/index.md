# ImageRendition Class

A class that represents one image placement in a document.

```
System.Object
    WebSupergoo.ABCpdf14.Operations.ImageRendition
```

## Methods

| Method | Description |
| --- | --- |
| [Focus](1-methods/focus.md) | Focus the document on the location of the image placement. |

## Properties

| Property | Description |
| --- | --- |
| [PageID](2-properties/pageid.md) | The ID of the Page on which the image is placed. |
| [Matrix](2-properties/matrix.md) | The transformation matrix for the placement of the image. |
| [BoundingBox](2-properties/boundingbox.md) | The bounding rectangle for the placement of the image. |
| [Dpi](2-properties/dpi.md) | The resolution of the image in dots per inch. |
| [DpiX](2-properties/dpix.md) | The horizontal resolution of the image in dots per inch. |
| [DpiY](2-properties/dpiy.md) | The vertical resolution of the image in dots per inch. |
| [StreamObject](2-properties/streamobject.md) | The StreamObject in which the image draw operation is contained. |
| [StreamOffset](2-properties/streamoffset.md) | The offset within the uncompressed StreamObject to the start of the drawing operation that contains this image draw operation. |
| [StreamLength](2-properties/streamlength.md) | The length within the uncompressed StreamObject of the drawing operation that contains this image draw operation. |
| [StreamID](2-properties/streamid.md) | The ID of the Stream in which the image draw operation is contained. |
