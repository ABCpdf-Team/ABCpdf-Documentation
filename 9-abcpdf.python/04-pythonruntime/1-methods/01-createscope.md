# CreateScope Function

Creates a scope for running Python code.

## Syntax

*C#*

[`PythonScope`](../../06-pythonscope/index.md)` CreateScope(string name = null)`

## Params

| Name | Description |
| :---: | --- |
| name | The name of the scope. |
| return | A Python scope. |

## Notes

Creates a scope for running Python code.
