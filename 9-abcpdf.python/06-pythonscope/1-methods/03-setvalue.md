# SetValue Function

Sets the variable to a value.

## Syntax

[C#]

```csharp
void SetValue(string name, string value)void SetValue(string name, bool value)void SetValue(string name, int value)void SetValue(string name, long value)void SetValue(string name, ulong value)void SetValue(string name, double value)
```

## Params

| **Name** | **Description** |
| --- | --- |
| name | The name of the variable. |
| value | The value of the variable. If it is null, None is used. |
