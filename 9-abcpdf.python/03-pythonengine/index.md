# PythonEngine Struct

Provides access to information about the Python engine. Members are operable after the Python environment is set up.

```
System.ValueType
   WebSupergoo.ABCpdf14.Python.PythonEngine
```

## Methods

| Method | Description |
| --- | --- |
| [PythonEngine](1-methods/01-pythonengine.md) | Creates an information accessor for the Python engine. |

## Properties

| Property | Description |
| --- | --- |
| [Version](2-properties/01-version.md) | Gets the version of the Python engine. |
| [BuildInfo](2-properties/02-buildinfo.md) | Gets the sequence number and the build date and time of the Python engine. |
| [Platform](2-properties/03-platform.md) | Gets the platform identifier for the current platform. |
| [Copyright](2-properties/04-copyright.md) | Gets the official copyright string for the Python version. |
| [Compiler](2-properties/05-compiler.md) | Gets, in square brackets, an indication of the compiler used to build the Python engine. |
