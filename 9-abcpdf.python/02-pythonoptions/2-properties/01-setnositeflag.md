# SetNoSiteFlag Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `bool` | false | No | Gets or sets whether to initialize the Python engine with NoSiteFlag enabled. |

## Notes

Gets or sets whether to initialize the Python engine with NoSiteFlag enabled.

It should be set to true to use a virtual environment. See [PythonRuntime.AutoInitializeRuntime](../../04-pythonruntime/1-methods/02-autoinitializeruntime.md) for an example.
