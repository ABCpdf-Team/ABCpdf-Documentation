# GetProperty Method

Gets this object's property.

## Syntax

```csharp
JSValue GetProperty(string name)
```

*C#*

⚠ `may throw Exception()`

## Params

| Name | Description |
| :---: | --- |
| name | The name of the property. |
| return | The value of the property. |

## Notes

The method gets the property with the specified name.
