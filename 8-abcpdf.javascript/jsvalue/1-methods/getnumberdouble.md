# GetNumberDouble Method

Gets the Double value of this number.

## Syntax

```csharp
double GetNumberDouble()
```

*C#*

⚠ `may throw Exception()`

## Params

| Name | Description |
| :---: | --- |
| return | The Double value. |

## Notes

The method returns the Double value of this number. It fails if this value is not a number.
