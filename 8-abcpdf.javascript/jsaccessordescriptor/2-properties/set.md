| --- | --- | --- | --- |
| `Func<`[`JSCallInfo`](../../jscallinfo/index.md)`, object>` | null | No | Gets or sets the setter for the new property. |

## Notes

Gets or sets the setter for the new property.

This property takes precedence over [JSSet](jsset.md) if it is non-null.
