# Height Property

## Notes

The height of the image in pixels.

Setting this property only changes the height recorded for the image. It does not change the image data, so the data and the dimensions of the image will no longer match. In general you should only set this property if you are also going to change the image data yourself.

To change the size of an image use the Resize method.
