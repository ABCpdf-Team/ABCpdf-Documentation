# FieldType Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `FieldType` | See description. | Yes | The field type. |

## Notes

The FieldType enumeration may take the following values:

- Pushbutton
- Checkbox
- Radio
- Text
- List
- Combo
- Signature
- Unknown

More details of these field types can be found in the Adobe PDF Specification.
