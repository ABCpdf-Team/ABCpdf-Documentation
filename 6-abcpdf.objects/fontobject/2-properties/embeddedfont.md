# EmbeddedFont Property

| Type | Default | Read Only | Description |
| --- | --- | --- | --- |
| [`StreamObject`](../../streamobject/index.md) | n/a | Yes | The embedded font file. |

## Notes

The embedded font file. This is null if the font is not embedded.

Font files may be in a number of different formats such as TrueType, OpenType or Type 1 - PostScript.
