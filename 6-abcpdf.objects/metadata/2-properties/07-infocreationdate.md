# InfoCreationDate Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | The CreationDate entry within the [Metadata](../index.md) |

## Notes

The CreationDate entry within the [Metadata](../index.md).

This corresponds to the xmp:CreateDate entry.

Use [StringAtom.StringToDate](../../../7-abcpdf.atoms/stringatom/1-methods/stringtodate.md) and DateToString to convert between DateTime and string formats.
