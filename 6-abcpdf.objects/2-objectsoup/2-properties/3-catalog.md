# Catalog Property

| Type | Default | Read Only | Description |
| --- | --- | --- | --- |
| [`Catalog`](../../catalog/index.md) | n/a | Yes | The Catalog for the document. |

## Notes

The [Catalog](../../catalog/index.md) for the document.

The Catalog is the root of the whole PDF document. It contains information on the root [Pages](../../pages/index.md) object and the [Outline](../../outline/index.md) object.
