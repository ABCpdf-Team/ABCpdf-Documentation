# Position Field

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `System.Windows.Vector` | n/a | No | The vector to use for positioning the glyph. |

## Notes

The vector to use for positioning the glyph.

Vertical metrics are only used when the FontObject [IsVertical](../../fontobject/2-properties/isvertical.md) property is true.
