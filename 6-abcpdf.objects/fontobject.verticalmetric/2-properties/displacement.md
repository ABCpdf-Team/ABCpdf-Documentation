# Displacement Field

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `System.Windows.Vector` | n/a | No | The vector to use for advancing the current text insertion point so that the next glyph can be positioned. |

## Notes

The vector to use for advancing the current text insertion point so that the next glyph can be positioned.

Vertical metrics are only used when the FontObject [IsVertical](../../fontobject/2-properties/isvertical.md) property is true.
