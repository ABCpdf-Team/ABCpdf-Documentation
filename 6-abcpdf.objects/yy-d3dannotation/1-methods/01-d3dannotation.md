# D3DAnnotation Function

Add 3D annotation to the current page of the doc.

## Syntax

*C#*

[`D3DAnnotation`](../index.md)`(Doc doc, XRect rect)`

## Params

| Name | Description |
| :---: | --- |
| doc | Doc |
| rect | Annotation rectangle |

## Notes

Add 3D annotation to the current page of the doc.
