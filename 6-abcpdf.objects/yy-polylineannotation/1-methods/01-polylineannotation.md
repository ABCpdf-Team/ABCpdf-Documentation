# PolylineAnnotation Function

Add polyline annotation to the current page of the doc.

## Syntax

*C#*

[`PolylineAnnotation`](../index.md)`(Doc doc, double[] vertices, XColor borderColor)`

## Params

| Name | Description |
| :---: | --- |
| doc | Doc |
| vertices | Polyline vertices |
| borderColor | Line color |

## Notes

Add polyline annotation to the current page of the doc.
