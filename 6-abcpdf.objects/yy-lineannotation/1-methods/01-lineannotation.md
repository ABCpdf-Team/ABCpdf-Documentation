# LineAnnotation Function

Add line annotation to the current page of the doc.

## Syntax

*C#*

[`LineAnnotation`](../index.md)`(Doc doc, XPoint p1, XPoint p2, XColor color)`

## Params

| Name | Description |
| :---: | --- |
| doc | Doc. |
| p1 | Line start point. |
| p2 | Line end point. |
| color | Color of the line. |

## Notes

Add line annotation to the current page of the doc.
