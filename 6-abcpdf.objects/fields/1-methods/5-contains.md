# Contains Function

Determines whether the collection contains a specific item.

## Syntax

*C#*

`bool Contains(`[`Field`](../../field/index.md)` value)`

## Params

| Name | Description |
| :---: | --- |
| value | The object to locate. |
| return | True if the object is found, otherwise false. |

## Notes

Determines whether the collection contains a specific item.
