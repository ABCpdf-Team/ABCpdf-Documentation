# FreeTextAnnotation Function

Add free text annotation to the current page of the doc.

## Syntax

*C#*

[`FreeTextAnnotation`](../index.md)`(Doc doc, XRect rect)`

## Params

| Name | Description |
| :---: | --- |
| doc | Doc |
| rect | Annotation rectangle |

## Notes

Add free text annotation to the current page of the doc.
