# GetLayers Function

Gets all the content Layers for the page.

## Syntax

*C#*

[`StreamObject`](../../streamobject/index.md)`[] GetLayers()`

## Params

| Name | Description |
| :---: | --- |
| return | An array of all the content Layers on the page. |

## Notes

Gets all the content [Layers](../../layer/index.md) for the page.
