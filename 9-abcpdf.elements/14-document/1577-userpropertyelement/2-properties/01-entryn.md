# EntryN Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "N" entry of the user property dictionary object. |

## Notes

Represents the "N" entry of the user property dictionary object.

It is a required entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF string object.

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 329, page 569.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=577)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 362, page 736.](https://www.iso.org/standard/63534.html)

The N entry holds the property name as a text string. Names are defined by the creating application and should avoid conflicts with other applications property names.
