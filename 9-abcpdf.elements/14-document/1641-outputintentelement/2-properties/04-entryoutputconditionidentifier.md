# EntryOutputConditionIdentifier Property

## Notes

Represents the "OutputConditionIdentifier" entry of the output intent dictionary object.

It is a required entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF string object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 365, page 634.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 401, page 815.

The OutputConditionIdentifier entry names the output condition. For registered conditions it must match an entry in the named registry. This is the key entry for color management lookup.
