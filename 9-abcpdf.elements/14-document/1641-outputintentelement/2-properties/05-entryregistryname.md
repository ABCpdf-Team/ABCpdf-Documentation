# EntryRegistryName Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "RegistryName" entry of the output intent dictionary object. |

## Notes

Represents the "RegistryName" entry of the output intent dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF string object.

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 365, page 634.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=642)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 401, page 815.](https://www.iso.org/standard/63534.html)

The RegistryName entry holds the URL of the registry where the output condition is defined. The ICC color profile registry at www.color.org is a common source.
