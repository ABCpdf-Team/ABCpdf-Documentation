# EntryOutputCondition Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "OutputCondition" entry of the output intent dictionary object. |

## Notes

Represents the "OutputCondition" entry of the output intent dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF string object.

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 365, page 633.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=641)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 401, page 814.](https://www.iso.org/standard/63534.html)

The OutputCondition entry holds a human-readable description of the intended output condition, such as the printing standard, substrate, and ink set.
