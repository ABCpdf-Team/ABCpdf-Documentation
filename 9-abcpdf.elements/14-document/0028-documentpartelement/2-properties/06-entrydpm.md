# EntryDPM Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`Element`](../../../01-base/1086-element/index.md) | null | No | Represents the "DPM" entry of the dpart dictionary object. |

## Notes

Represents the "DPM" entry of the dpart dictionary object.

It is an optional entry defined as part of the PDF 2.0 specification.

It contains an [Element](../../../01-base/1086-element/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 409, page 830.](https://www.iso.org/standard/63534.html)

The DPM entry holds a document part metadata dictionary with application-specific properties for this part. Its contents are defined by the workflow or specification using the hierarchy, not by PDF itself.
