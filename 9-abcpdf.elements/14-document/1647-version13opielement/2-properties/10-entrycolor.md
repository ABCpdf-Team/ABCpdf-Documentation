# EntryColor Property

## Notes

Represents the "Color" entry of the version 1.3 opi dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an array which contains Elements.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 369, page 641.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 406, page 824.

The Color entry describes the image colorants. Its structure depends on ColorType: an array of component names for process colors, or spot color definition data for spot colors.
