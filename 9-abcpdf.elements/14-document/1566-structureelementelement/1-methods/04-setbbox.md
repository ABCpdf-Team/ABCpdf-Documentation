# SetBBox Function

Sets the bounding box for this structure element.

## Syntax

*C#*

[`StandardLayoutAttributesElement`](../../1605-standardlayoutattributeselement/index.md)` SetBBox(`[`XRect`](../../../../5-abcpdf/xrect/index.md)` bbox)`

## Params

| Name | Description |
| :---: | --- |
| bbox | The bounding box. |
| return | The standard layout attributes element in which the BBox was set. |

## Notes

Sets the bounding box for this structure element.
