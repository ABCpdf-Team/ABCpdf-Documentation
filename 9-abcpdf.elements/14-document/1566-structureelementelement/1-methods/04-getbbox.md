# GetBBox Function

Get the bounding box for the structure element.

## Syntax

[C#]

```csharp
<a href="../../../../5-abcpdf/xrect/default.htm">XRect</a> GetBBox()
```

## Params

| **Name** | **Description** |
| --- | --- |
| return | The bounding box. |

## Notes

Get the bounding box for the structure element.

This will return null if there is no bounding box.
