# EntryC Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`Element`](../../../01-base/1086-element/index.md) | null | No | Represents the "C" entry of the web capture command settings dictionary object. |

## Notes

Represents the "C" entry of the web capture command settings dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an [Element](../../../01-base/1086-element/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 359, page 626.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=634)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 395, page 806.](https://www.iso.org/standard/63534.html)

The C entry holds a dictionary of content-type-specific settings keyed by MIME type, allowing different handling rules for HTML, images, and other media types.
