# EntryG Property

## Notes

Represents the "G" entry of the web capture command settings dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an Element.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 359, page 626.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 395, page 806.

The G entry holds a dictionary of global capture settings applying to all content types, controlling spider-wide parameters such as connection limits and retry behaviour.
