# Entry20 Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`Version20OpiElement`](../../1649-version20opielement/index.md) | null | No | Represents the "2. |

## Notes

Represents the "2.0" entry of the opi version dictionary object.

It is an optional entry defined as part of the PDF 1.2 specification.

It contains a [Version20OpiElement](../../1649-version20opielement/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 368, page 639.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=647)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 405, page 823.](https://www.iso.org/standard/63534.html)

The 2.0 entry references a version 2.0 OPI dictionary. Version 2.0 OPI processors prefer this over the 1.3 entry when both are present.
