# EntryInlineAlign Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "InlineAlign" entry of the standard layout attributes object. |

## Notes

Represents the "InlineAlign" entry of the standard layout attributes object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF name object.

The PDF specification states that this item assumes a value of "Start" if no value has been provided.

This item may take one of the following valid values:.

- Start
- Center
- End

The InlineAlign entry specifies content alignment in the inline direction when the block is wider than its content: Start, Center, or End.
