# EntryProfileName Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "ProfileName" entry of the destoutputprofileref dictionary object. |

## Notes

Represents the "ProfileName" entry of the destoutputprofileref dictionary object.

It is defined as part of the PDF 1.0 specification.

It contains a string representing a PDF string object.

For definitive details see:.

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 402, page 817.](https://www.iso.org/standard/63534.html)

The ProfileName entry holds the name of the ICC profile as a text string, typically from the profile description tag, provided here for display without decoding the profile stream.
