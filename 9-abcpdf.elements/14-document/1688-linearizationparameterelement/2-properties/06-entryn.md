# EntryN Property

## Notes

Represents the "N" entry of the linearization parameter dictionary object.

It is a required entry defined as part of the PDF 1.2 specification.

It contains an integer representing a PDF numeric object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: f.1, page 680.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: f.1, page 877.

The N entry gives the total number of pages in the document, allowing navigation controls to be initialised before the entire document has been downloaded.
