# EntryNS Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`NamespaceElement`](../../0030-namespaceelement/index.md) | null | No | Represents the "NS" entry of the attribute object dictionary object. |

## Notes

Represents the "NS" entry of the attribute object dictionary object.

It is defined as part of the PDF 2.0 specification.

It contains a [NamespaceElement](../../0030-namespaceelement/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 327, page 567.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=575)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 360, page 734.](https://www.iso.org/standard/63534.html)

The NS entry associates this attribute dictionary with a specific namespace, used when the attribute owner corresponds to a namespace rather than one of the built-in PDF attribute owners.
