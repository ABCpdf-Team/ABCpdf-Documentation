# EntryCreator Property

## Notes

Represents the "Creator" entry of the optional content usage creator dictionary object.

It is a required entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF string object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 102, page 232.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 100, page 284.

The Creator string names the application that set the usage metadata on the associated optional content group. This is informational and may help other tools understand the context in which the usage was defined.
