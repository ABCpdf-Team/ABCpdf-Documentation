# EntryOFF Property

## Notes

Represents the "OFF" entry of the optional content configuration dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an array which contains OptionalContentGroupElements.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 101, page 229.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 99, page 282.

The OFF array lists optional content groups that should be set to off regardless of the BaseState. Groups in this list are hidden when this configuration is applied.
