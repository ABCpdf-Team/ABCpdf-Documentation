# EntryCreator Property

## Notes

Represents the "Creator" entry of the optional content configuration dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF string object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 101, page 229.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 99, page 281.

The Creator string identifies the application that produced this configuration. It is informational and does not affect rendering or optional content processing.
