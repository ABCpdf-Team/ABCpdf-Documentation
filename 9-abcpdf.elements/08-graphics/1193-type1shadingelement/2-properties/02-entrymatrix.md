# EntryMatrix Property

## Notes

Represents the "Matrix" entry of the type 1 shading dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an array which contains doubles, representing PDF numeric objects.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 79, page 185.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 78, page 230.

The Matrix maps the shading's coordinate system to the coordinate system in which it is used (pattern space or user space). It allows the function-based shading to be positioned and oriented independently of its function definition.
