| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |

## Notes

The [StreamElement](../../../07-syntax/1028-streamelement/index.md) associated with this class.

The stream holds the tensor-product patch mesh data. Each patch record contains a flag, 16 control point coordinates, and 4 corner color values, packed according to the declared bit depths.
