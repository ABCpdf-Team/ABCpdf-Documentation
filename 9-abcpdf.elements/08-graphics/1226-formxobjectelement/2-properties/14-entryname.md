# EntryName Property

## Notes

Represents the "Name" entry of the form XObject dictionary object.

It is defined as part of the PDF 1.0 specification. It was marked obsolescent in PDF 1.7 and deprecated in PDF 2.0.

It contains a string representing a PDF name object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 95, page 219.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 4.45, page 27.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 93, page 270.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 363, page 632.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 399, page 812.

The Name entry holds a name used in PDF 1.0 and 1.1 to identify the form. It is kept for backward compatibility. In current PDF, forms are identified by their resource name in the enclosing context's resource dictionary.
