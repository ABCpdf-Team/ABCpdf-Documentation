# EntryMax Property

## Notes

Represents the "max" entry of the optional content usage zoom dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a double representing a PDF numeric object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 102, page 232.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 100, page 284.

The max value gives the maximum magnification factor at which this group is visible. When the viewer's zoom exceeds this value, the group may be turned off automatically. A very large value effectively means no upper bound.
