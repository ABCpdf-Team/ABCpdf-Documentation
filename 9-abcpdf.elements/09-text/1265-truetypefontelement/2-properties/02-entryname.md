# EntryName Property

## Notes

Represents the "Name" entry of the truetype font dictionary object.

It is defined as part of the PDF 1.0 specification.

It contains a string representing a PDF name object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; page 257.

This entry is obsolete. It was used in early PDF versions to name the font resource in the page resource dictionary, but this usage was deprecated in later specifications.

New documents should not include it. Its presence should be ignored by conforming viewers.
