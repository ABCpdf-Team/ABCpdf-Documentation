# EntryLength2 Property

## Notes

Represents the "Length2" entry of the embedded font stream dictionary object.

It is defined as part of the PDF 1.0 specification.

It contains an integer representing a PDF numeric object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 127, page 290.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 125, page 350.

For Type 1 programs only, this gives the length of the encrypted binary section that follows the clear-text section. The binary section contains the font's private charstring data.
