# EntryBS Property

## Notes

Represents the "BS" entry of the link annotation object.

It is an optional entry defined as part of the PDF 1.6 specification.

It contains a BorderStyleElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 173, page 395.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 176, page 480.

The border style dictionary controls the width, style, and dash pattern of the link rectangle's visible border.
