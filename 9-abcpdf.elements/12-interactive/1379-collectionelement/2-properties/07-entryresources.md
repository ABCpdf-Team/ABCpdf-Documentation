# EntryResources Property

## Notes

Represents the "Resources" entry of the collection dictionary object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a NameTreeNodeElement containing StreamElements.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 155, page 371.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.6, page 29.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 153, page 445.

The resources dictionary provides fonts, colour spaces, and other PDF resources available to the portfolio's navigator component during rendering.
