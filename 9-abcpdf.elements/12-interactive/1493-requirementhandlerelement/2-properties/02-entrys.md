# EntryS Property

## Notes

Represents the "S" entry of the requirement handler dictionary object.

It is a required entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF name object.

This item may take one of the following valid values:.

JSNoOp

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 265, page 485.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 276, page 608.

The handler subtype classifies the kind of handler. JS indicates a JavaScript-based handler.
