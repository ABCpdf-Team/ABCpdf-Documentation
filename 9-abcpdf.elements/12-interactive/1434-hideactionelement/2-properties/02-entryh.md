# EntryH Property

## Notes

Represents the "H" entry of the hide action object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a bool representing a PDF boolean object.

The PDF specification states that this item assumes a value of true if no value has been provided.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 210, page 426.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 214, page 518.

When true the annotation's Hidden flag is set, making it invisible and non-interactive. When false the flag is cleared.
