# EntryA Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`Element`](../../../01-base/1086-element/index.md) | null | No | Represents the "A" entry of the richmediacommand dictionary object. |

## Notes

Represents the "A" entry of the richmediacommand dictionary object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

The specification defines this property as being of any type. So any type of atom or data content is valid.

It contains an [Element](../../../01-base/1086-element/index.md).

For definitive details see:.

[Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.48b, page 41.](http://www.adobe.com/content/dam/Adobe/en/devnet/acrobat/pdfs/adobe_supplement_iso32000.pdf#page=41)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 223, page 524.](https://www.iso.org/standard/63534.html)

The arguments array contains strings passed to the player as the command's parameters. The number and meaning of arguments depend on the command name.
