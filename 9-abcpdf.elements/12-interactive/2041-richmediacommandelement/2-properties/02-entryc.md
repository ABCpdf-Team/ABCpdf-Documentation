# EntryC Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "C" entry of the richmediacommand dictionary object. |

## Notes

Represents the "C" entry of the richmediacommand dictionary object.

It is a required entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a string representing a PDF string object.

For definitive details see:.

[Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.48b, page 41.](http://www.adobe.com/content/dam/Adobe/en/devnet/acrobat/pdfs/adobe_supplement_iso32000.pdf#page=41)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 223, page 524.](https://www.iso.org/standard/63534.html)

The command name string identifies the operation to execute in the rich media player. Valid command names depend on the media type and the player's exposed API.
