# EntryMovie Property

## Notes

Represents the "Movie" entry of the movie annotation object.

It is a required entry defined as part of the PDF 1.0 specification.

It contains a MovieElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 186, page 407.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 189, page 493.

The movie dictionary holds the file specification for the movie file and parameters such as the poster frame, aspect ratio, and whether the movie should play in a floating window.
