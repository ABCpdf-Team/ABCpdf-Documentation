# EntryTI Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `int?` | null | No | Represents the "TI" entry of the combo field object. |

## Notes

Represents the "TI" entry of the combo field object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an integer representing a PDF numeric object.

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 231, page 445.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=453)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 234, page 539.](https://www.iso.org/standard/63534.html)

The top index is the zero-based index into the Opt array of the option scrolled to the top of the visible list area, independently of the selected item.
