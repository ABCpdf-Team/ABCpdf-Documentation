# EntrySS Property

## Notes

Represents the "SS" entry of the transition dictionary object.

It is an optional entry defined as part of the PDF 1.5 specification.

It contains a double representing a PDF numeric object.

The PDF specification states that this item assumes a value of 1 if no value has been provided.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 162, page 379.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 164, page 460.

The scale entry applies to the Fly transition. It gives the starting scale of the incoming page when the transition begins.
