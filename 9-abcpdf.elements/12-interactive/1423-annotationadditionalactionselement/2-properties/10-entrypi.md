# EntryPI Property

## Notes

Represents the "PI" entry of the annotation additional-actions dictionary object.

It is an optional entry defined as part of the PDF 1.5 specification.

It contains an ActionElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 194, page 416.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 197, page 504.

The page-invisible action fires when the annotation's page is no longer visible, for example when scrolling past it.
