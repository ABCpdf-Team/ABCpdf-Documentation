# EntryParent Property

## Notes

Represents the "Parent" entry of the folder dictionary object.

It is defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a FolderElement.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.6c, page 32.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 159, page 451.

The Parent entry references the enclosing folder. Root-level folders have no parent; all other folders must reference their containing folder.
