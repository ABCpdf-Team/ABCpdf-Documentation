# EntryIT Property

## Notes

Represents the "IT" entry of the projection annotation object.

It is an optional entry defined as part of the PDF 1.6 specification.

It contains a string representing a PDF name object.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: page39, page 39.

The intent type classifies the kind of 3D projection this annotation represents. Defined values correspond to specific measurement or comment types within a 3D scene, such as a linear dimension, angular measurement, or comment note.
