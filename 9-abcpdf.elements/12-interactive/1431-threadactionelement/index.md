# ThreadActionElement Class

This class represents the thread action. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 205, page 423.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=431)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 209, page 514.](https://www.iso.org/standard/63534.html)

`System.Object`

A thread action navigates to a specific article thread and optionally to a specific bead within that thread. The F entry identifies the thread by index or title string. The B entry specifies a starting bead.
