# EntryType Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "Type" entry of the projected coordinate system dictionary object. |

## Notes

Represents the "Type" entry of the projected coordinate system dictionary object.

It is a required entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a string representing a PDF name object.

This item must always be provided and must always take the value "PROJCS".

For definitive details see:.

[Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.111c, page 52.](http://www.adobe.com/content/dam/Adobe/en/devnet/acrobat/pdfs/adobe_supplement_iso32000.pdf#page=52)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 271, page 601.](https://www.iso.org/standard/63534.html)
