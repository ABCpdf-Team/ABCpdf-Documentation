# FDFNamedPageReferenceElement Class

This class represents the fdf named page reference dictionary. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 250, page 464.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=472)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 253, page 562.](https://www.iso.org/standard/63534.html)

`System.Object`  
`    `[`WebSupergoo.ABCpdf14.Elements.Element`](../../01-base/1086-element/index.md)  
`       WebSupergoo.ABCpdf14.Elements.FDFNamedPageReferenceElement`

An FDF named page reference dictionary identifies a specific page in a PDF file by its named destination, allowing the FDF to refer to a page without knowing its page index. The Name entry gives the destination name and F identifies the containing PDF.
