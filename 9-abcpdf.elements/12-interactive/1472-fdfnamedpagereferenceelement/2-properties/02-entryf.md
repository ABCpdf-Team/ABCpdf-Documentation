# EntryF Property

## Notes

Represents the "F" entry of the fdf named page reference dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a FileSpecificationElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 250, page 464.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 253, page 562.

The file specification identifies the PDF containing the named page. If absent the name is resolved in the current document.
