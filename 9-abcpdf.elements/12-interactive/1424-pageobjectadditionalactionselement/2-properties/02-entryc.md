# EntryC Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`ActionElement`](../../1422-actionelement/index.md) | null | No | Represents the "C" entry of the page object additional-actions dictionary object. |

## Notes

Represents the "C" entry of the page object additional-actions dictionary object.

It is an optional entry defined as part of the PDF 1.2 specification.

It contains an [ActionElement](../../1422-actionelement/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 195, page 416.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=424)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 198, page 505.](https://www.iso.org/standard/63534.html)

The page-close action fires as the viewer leaves this page. It can pause media, save state, or perform any cleanup needed when the page is no longer current.
