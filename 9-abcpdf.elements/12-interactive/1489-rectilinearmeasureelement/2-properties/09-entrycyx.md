# EntryCYX Property

## Notes

Represents the "CYX" entry of the rectilinear measure dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a double representing a PDF numeric object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 262, page 482.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 267, page 595.

The conversion factor from y to x units. When CYX is present and not equal to 1.0 the x and y axes use different physical scales, enabling non-square coordinate grids.
