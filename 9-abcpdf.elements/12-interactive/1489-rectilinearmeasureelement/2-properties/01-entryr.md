# EntryR Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "R" entry of the rectilinear measure dictionary object. |

## Notes

Represents the "R" entry of the rectilinear measure dictionary object.

It is a required entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF string object.

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 262, page 481.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=489)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 267, page 594.](https://www.iso.org/standard/63534.html)

The scale ratio text string expresses the mapping as a human-readable equation such as '1 in = 10 ft'. It is for display purposes; the actual conversion factors are in the X, Y, and D number format arrays.
