# EntryPosition Property

## Notes

Represents the "Position" entry of the richmediawindow dictionary object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a RichMediaPositionElement.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.50e, page 84.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 339, page 702.

The position entry references a rich media position element specifying the alignment and offset of the window relative to the viewport or annotation rectangle.
