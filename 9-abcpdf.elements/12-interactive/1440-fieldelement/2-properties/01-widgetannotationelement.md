# WidgetAnnotationElement Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`WidgetAnnotationElement`](../../1416-widgetannotationelement/index.md) | null | Yes | Any [WidgetAnnotationElement](../../1416-widgetannotationelement/index.md) associated with this Field. |

## Notes

Any [WidgetAnnotationElement](../../1416-widgetannotationelement/index.md) associated with this Field.

When a field and its single widget are merged into a single dictionary this entry provides access to the widget's visual properties. The combined dictionary contains both field entries (FT, T, V, etc.) and annotation entries (Rect, AP, etc.).
