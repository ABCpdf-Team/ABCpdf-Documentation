# EntryT Property

## Notes

Represents the "T" entry of the field dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF string object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 220, page 433.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 226, page 527.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 222, page 434.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 228, page 529.

The partial name is the rightmost component of the fully qualified name and must not contain a period. Combining all T values from the root to a leaf, separated by periods, gives the fully qualified name used for data export and reference.
