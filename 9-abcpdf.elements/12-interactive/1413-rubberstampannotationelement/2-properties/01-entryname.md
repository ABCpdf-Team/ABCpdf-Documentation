# EntryName Property

## Notes

Represents the "Name" entry of the rubber stamp annotation object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF name object.

The PDF specification states that this item assumes a value of "Draft" if no value has been provided.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 181, page 405.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 184, page 490.

The Name entry selects the stamp graphic. Standard names include Approved, Experimental, NotApproved, AsIs, Expired, NotForPublicRelease, Confidential, Final, Sold, Departmental, ForComment, TopSecret, Draft, ForPublicRelease, and Void.
