# FieldMDPTransformParametersElement Class

This class represents the fieldmdp transform parameters dictionary. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 256, page 473.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=481)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 259, page 572.](https://www.iso.org/standard/63534.html)

`System.Object`  
`    `[`WebSupergoo.ABCpdf14.Elements.Element`](../../01-base/1086-element/index.md)  
`       `[`WebSupergoo.ABCpdf14.Elements.TransformParametersElement`](../1478-transformparameterselement/index.md)

A FieldMDP transform parameters dictionary specifies which form fields are covered by the signature. The Action entry selects All, Include, or Exclude. The Fields array lists the targeted field names.
