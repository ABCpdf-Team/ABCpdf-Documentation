# EntryV Property

## Notes

Represents the "V" entry of the docmdp transform parameters dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF name object.

The PDF specification states that this item assumes a value of "1.2" if no value has been provided.

This item may take one of the following valid values:.

1.21

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 254, page 471.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 257, page 570.

The version number identifies the revision of the DocMDP transform specification. Only version 1.2 is currently defined.
