# EntryIcon Property

## Notes

Represents the "Icon" entry of the navigator dictionary object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a string representing a PDF string object.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.6d, page 34.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 160, page 454.

The icon entry references an image or form XObject used as a thumbnail representing this navigator in any selection UI.
