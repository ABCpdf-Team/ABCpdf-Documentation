# FieldElement Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`FieldElement`](../../1440-fieldelement/index.md) | null | Yes | Any [FieldElement](../../1440-fieldelement/index.md) associated with this Widget Annotation. |

## Notes

Any [FieldElement](../../1440-fieldelement/index.md) associated with this Widget Annotation.

The FieldElement entry provides access to the interactive form field dictionary that this widget represents. The field holds the value, type, and flags; the widget holds the geometry and visual characteristics.
