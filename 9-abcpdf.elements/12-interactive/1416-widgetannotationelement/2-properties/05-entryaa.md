# EntryAA Property

## Notes

Represents the "AA" entry of the widget annotation object.

It is an optional entry defined as part of the PDF 1.2 specification.

It contains an AnnotationAdditionalActionsElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 188, page 409.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.39, page 39.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 191, page 495.

The widget's additional actions dictionary associates actions with annotation-level events: cursor entry and exit, mouse press and release, and focus and blur.
