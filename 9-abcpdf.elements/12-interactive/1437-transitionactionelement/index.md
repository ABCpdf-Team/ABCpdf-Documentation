# TransitionActionElement Class

This class represents the transition action. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 215, page 429.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=437)

A transition action triggers a page transition effect directly, independent of a page change. The Trans entry holds a complete transition dictionary describing the style, direction, and duration.
