# EntrySubtype Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "Subtype" entry of the external data dictionary object. |

## Notes

Represents the "Subtype" entry of the external data dictionary object.

It is defined as part of the PDF 1.0 specification.

It contains a string representing a PDF name object.

This can be anything but common values include 3D, Markup3D, 3DM and MarkupGeo.

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 170, page 391.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=399)
