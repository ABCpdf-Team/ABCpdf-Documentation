# EntryA Property

## Notes

Represents the "A" entry of the screen annotation object.

It is an optional entry defined as part of the PDF 1.1 specification.

It contains an ActionElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 187, page 408.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 190, page 494.

The action dictionary fires when the user activates the annotation, typically a rendition action that starts media playback.
