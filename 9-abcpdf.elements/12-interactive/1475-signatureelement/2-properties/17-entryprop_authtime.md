# EntryProp_AuthTime Property

## Notes

Represents the "Prop_AuthTime" entry of the signature dictionary object.

It is an optional entry defined as part of the PDF 1.5 specification.

It contains an integer representing a PDF numeric object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 252, page 469.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 255, page 567.

The Prop_AuthTime integer records the time of the signing event as a Unix timestamp in seconds.
