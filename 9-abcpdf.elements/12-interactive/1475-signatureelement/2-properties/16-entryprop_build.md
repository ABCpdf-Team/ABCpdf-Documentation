# EntryProp_Build Property

## Notes

Represents the "Prop_Build" entry of the signature dictionary object.

It is an optional entry defined as part of the PDF 1.5 specification.

It contains an Element.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 252, page 469.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 255, page 567.

The Prop_Build dictionary records information about the application, operating system, and other environment components involved in creating the signature. It is informational metadata embedded by the signing application.
