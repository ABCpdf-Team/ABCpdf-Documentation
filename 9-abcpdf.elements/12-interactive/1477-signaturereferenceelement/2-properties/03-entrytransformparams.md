# EntryTransformParams Property

## Notes

Represents the "TransformParams" entry of the signature reference dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an Element.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 253, page 469.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 256, page 568.

The transform parameters dictionary holds the configuration specific to the chosen transform method.
