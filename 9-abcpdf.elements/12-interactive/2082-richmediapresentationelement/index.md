# RichMediaPresentationElement Class

This class represents the richmediapresentation dictionary. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 338, page 701.](https://www.iso.org/standard/63534.html)

[Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.50d, page 82.](http://www.adobe.com/content/dam/Adobe/en/devnet/acrobat/pdfs/adobe_supplement_iso32000.pdf#page=82)

`System.Object`  
`    `[`WebSupergoo.ABCpdf14.Elements.Element`](../../01-base/1086-element/index.md)  
`       WebSupergoo.ABCpdf14.Elements.RichMediaPresentationElement`

A rich media presentation dictionary describes how the media player window is displayed. The Style entry selects Embedded, Windowed, or Fullscreen. Window, Transparent, NavigationPane, Toolbar, and PassContextClick control the media player's display characteristics.
