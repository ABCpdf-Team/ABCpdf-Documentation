# EntryIT Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | Represents the "IT" entry of the caret annotation object. |

## Notes

Represents the "IT" entry of the caret annotation object.

It is an optional entry defined as part of the PDF 1.6 specification.

It contains a string representing a PDF name object.

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 180, page 404.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=412)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 183, page 489.](https://www.iso.org/standard/63534.html)

The intent type may distinguish insertion marks from replacement or correction marks in a review workflow.
