# EntryIT Property

## Notes

Represents the "IT" entry of the caret annotation object.

It is an optional entry defined as part of the PDF 1.6 specification.

It contains a string representing a PDF name object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 180, page 404.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 183, page 489.

The intent type may distinguish insertion marks from replacement or correction marks in a review workflow.
