# EntryF Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`FileSpecificationElement`](../../../07-syntax/0011-filespecificationelement/index.md) | null | No | Represents the "F" entry of the remote go-to action object. |

## Notes

Represents the "F" entry of the remote go-to action object.

It is a required entry defined as part of the PDF 1.0 specification.

It contains a [FileSpecificationElement](../../../07-syntax/0011-filespecificationelement/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 200, page 419.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=427)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 203, page 508.](https://www.iso.org/standard/63534.html)

The file specification identifies the external PDF to open. It may be a path string or a full file specification dictionary.
