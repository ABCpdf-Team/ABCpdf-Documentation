# EntryTarget Property

## Notes

Represents the "Target" entry of the fdf dictionary object.

It is an optional entry defined as part of the PDF 1.4 specification.

It contains a string representing a PDF string object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 243, page 460.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 246, page 557.

The target entry specifies which document the FDF data should be applied to when the F entry alone is insufficient, for example when the target is a form within a compound document.
