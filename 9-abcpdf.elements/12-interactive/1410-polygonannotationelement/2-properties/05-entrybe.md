# EntryBE Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`BorderEffectElement`](../../1395-bordereffectelement/index.md) | null | No | Represents the "BE" entry of the polygon annotation object. |

## Notes

Represents the "BE" entry of the polygon annotation object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a [BorderEffectElement](../../1395-bordereffectelement/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 178, page 403.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=411)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 181, page 488.](https://www.iso.org/standard/63534.html)

The border effect applies a visual treatment such as a cloudy edge to the polygon boundary.
