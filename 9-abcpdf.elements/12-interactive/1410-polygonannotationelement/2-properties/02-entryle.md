# EntryLE Property

## Notes

Represents the "LE" entry of the polygon annotation object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an array which contains Elements.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 178, page 402.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 181, page 487.

Although a polygon is closed the LE entry may specify a line-end style for the vertex at which the closure occurs.
