# SignatureFieldTimeStampElement Class

This class represents the signature field time stamp dictionary. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 234, page 447.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=455)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 237, page 542.](https://www.iso.org/standard/63534.html)

`System.Object`  
`    `[`WebSupergoo.ABCpdf14.Elements.Element`](../../01-base/1086-element/index.md)  
`       WebSupergoo.ABCpdf14.Elements.SignatureFieldTimeStampElement`

A signature field time stamp dictionary supplies the URL of a time-stamping authority for use when the field is signed. The Ff entry uses a flag bit to indicate whether use of this TSA is mandatory.
