# EntryIF Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`IconFitElement`](../../1471-iconfitelement/index.md) | null | No | Represents the "IF" entry of the appearance characteristics dictionary object. |

## Notes

Represents the "IF" entry of the appearance characteristics dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an [IconFitElement](../../1471-iconfitelement/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 189, page 410.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=418)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 192, page 497.](https://www.iso.org/standard/63534.html)

The icon fit dictionary controls how the icon form XObject is scaled and positioned within the widget rectangle.
