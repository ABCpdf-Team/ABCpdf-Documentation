# EntryNext Property

## Notes

Represents the "Next" entry of the outline item dictionary object.

It is defined as part of the PDF 1.0 specification.

It contains an OutlineItemElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 153, page 368.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 151, page 442.

This entry links the item to its following sibling at the same outline level. If absent the item is the last child of its parent.
