# EntryTime Property

## Notes

Represents the "Time" entry of the cuepoint dictionary object.

It is a required entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a double representing a PDF numeric object.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.51e, page 92.

The time value is a real number giving the position in seconds from the start of the media stream at which this cue point is triggered.
