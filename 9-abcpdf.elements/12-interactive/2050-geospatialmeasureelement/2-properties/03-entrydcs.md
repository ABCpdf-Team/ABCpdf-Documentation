# EntryDCS Property

## Notes

Represents the "DCS" entry of the geospatial measure dictionary object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a ProjectedCoordinateSystemElement.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.111a, page 50.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 269, page 598.

The display coordinate system dictionary describes the coordinate system of the PDF page itself, which may be a projected coordinate system.
