# EntryDeactivation Property

## Notes

Represents the "Deactivation" entry of the richmediasettings dictionary object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a RichMediaDeactivationElement.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.50, page 78.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 334, page 697.

The deactivation dictionary specifies the trigger condition that causes the media to stop: page close, page invisible, or explicit user action.
