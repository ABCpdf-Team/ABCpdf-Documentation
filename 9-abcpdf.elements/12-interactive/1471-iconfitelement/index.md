# IconFitElement Class

This class represents the icon fit dictionary. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 247, page 463.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=471)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 250, page 560.](https://www.iso.org/standard/63534.html)

`System.Object`  
`    `[`WebSupergoo.ABCpdf14.Elements.Element`](../../01-base/1086-element/index.md)  
`       WebSupergoo.ABCpdf14.Elements.IconFitElement`

An icon fit dictionary controls how a button widget's icon is scaled and positioned within the widget's inner rectangle. The SW (scale when) entry controls the scaling trigger; S selects proportional or anamorphic scaling; A gives alignment fractions; FB determines whether border width is accounted for.
