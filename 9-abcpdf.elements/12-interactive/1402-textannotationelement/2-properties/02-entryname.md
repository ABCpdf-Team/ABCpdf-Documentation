# EntryName Property

## Notes

Represents the "Name" entry of the text annotation object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a string representing a PDF name object.

The PDF specification states that this item assumes a value of "Note" if no value has been provided.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 172, page 394.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 175, page 478.

The icon name selects the visual icon. Standard names include Note, Comment, Help, Insert, Key, NewParagraph, Paragraph, and Check. An unrecognised name results in a viewer-default icon.
