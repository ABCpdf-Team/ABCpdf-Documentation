# EntryBBox Property

## Notes

Represents the "BBox" entry of the viewport dictionary object.

It is a required entry defined as part of the PDF 1.0 specification.

It contains a RectangleElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 260, page 479.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.109, page 48.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 265, page 592.

The bounding box defines the viewport region in default user space. It must be contained within the page's media box. Only content within this box is included in the coordinate mapping.
