# EntryBS Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`BorderStyleElement`](../../1394-borderstyleelement/index.md) | null | No | Represents the "BS" entry of the ink annotation object. |

## Notes

Represents the "BS" entry of the ink annotation object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a [BorderStyleElement](../../1394-borderstyleelement/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 182, page 405.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=413)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 185, page 491.](https://www.iso.org/standard/63534.html)

The border style dictionary controls the width and dash pattern used to render all strokes in the ink list.
