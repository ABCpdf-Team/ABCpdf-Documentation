# EntryIT Property

## Notes

Represents the "IT" entry of the circle annotation object.

It is an optional entry defined as part of the PDF 1.6 specification.

It contains a string representing a PDF name object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 177, page 401.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 180, page 486.

For circle annotations the intent type may indicate a specific use such as a measurement ellipse.
