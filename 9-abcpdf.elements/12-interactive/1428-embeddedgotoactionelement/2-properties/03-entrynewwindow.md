# EntryNewWindow Property

## Notes

Represents the "NewWindow" entry of the embedded go-to action object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a bool representing a PDF boolean object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 201, page 420.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 204, page 510.

Controls whether the target file is displayed in a new window. Behaviour is viewer-dependent when absent.
