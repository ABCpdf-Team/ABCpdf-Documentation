# EntryT Property

## Notes

Represents the "T" entry of the markup annotation object.

It is an optional entry defined as part of the PDF 1.1 specification.

It contains a string representing a PDF string object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 170, page 391.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.21, page 38.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 332, page 695.

The author string identifies who created or last modified the annotation, shown in the pop-up header and in annotation summary views.
