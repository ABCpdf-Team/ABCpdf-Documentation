# EntryIT Property

## Notes

Represents the "IT" entry of the text annotation object.

It is an optional entry defined as part of the PDF 1.6 specification.

It contains a string representing a PDF name object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 172, page 394.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 175, page 478.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.21, page 38.

## Example

The intent type classifies the annotation's purpose within its subtype, for example distinguishing a callout from a standard note or a dimension line from a plain line.
