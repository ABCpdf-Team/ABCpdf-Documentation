# EntryNonEmbeddedFonts Property

## Notes

Represents the "NonEmbeddedFonts" entry of the legal attestation dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an integer representing a PDF numeric object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 259, page 478.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 264, page 590.

The integer counts fonts not embedded in the document. Non-embedded fonts are substituted by the viewer and the substituted rendering may differ from what the signer saw.
