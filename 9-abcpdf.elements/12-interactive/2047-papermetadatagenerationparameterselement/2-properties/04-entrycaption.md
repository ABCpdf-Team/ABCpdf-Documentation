# EntryCaption Property

## Notes

Represents the "Caption" entry of the papermetadata generation parameters dictionary object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a string representing a PDF string object.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.39b, page 47.

When true a human-readable text caption is printed alongside the barcode.
