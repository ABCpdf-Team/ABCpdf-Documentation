# EntryECC Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `double?` | null | No | Represents the "ECC" entry of the papermetadata generation parameters dictionary object. |

## Notes

Represents the "ECC" entry of the papermetadata generation parameters dictionary object.

It is defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a double representing a PDF numeric object.

For definitive details see:.

[Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.39b, page 47.](http://www.adobe.com/content/dam/Adobe/en/devnet/acrobat/pdfs/adobe_supplement_iso32000.pdf#page=47)

The error correction level controls the amount of redundancy encoded in the barcode, increasing the ability to survive damage at the cost of data capacity.
