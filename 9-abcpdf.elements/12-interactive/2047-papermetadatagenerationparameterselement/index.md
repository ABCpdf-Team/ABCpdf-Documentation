# PaperMetaDataGenerationParametersElement Class

This class represents the papermetadata generation parameters dictionary. This is definitively detailed in:.

[Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 8.39b, page 47.](http://www.adobe.com/content/dam/Adobe/en/devnet/acrobat/pdfs/adobe_supplement_iso32000.pdf#page=47)

`System.Object`  
`    `[`WebSupergoo.ABCpdf14.Elements.Element`](../../01-base/1086-element/index.md)  
`       WebSupergoo.ABCpdf14.Elements.PaperMetaDataGenerationParametersElement`

A paper metadata generation parameters dictionary holds parameters used when generating a paper barcode or metadata glyph for a document: symbology, dimensions, error correction level, and encoding grid dimensions.
