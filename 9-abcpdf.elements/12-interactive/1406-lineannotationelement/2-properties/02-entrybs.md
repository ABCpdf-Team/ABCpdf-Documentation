# EntryBS Property

## Notes

Represents the "BS" entry of the line annotation object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a BorderStyleElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 175, page 398.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 178, page 482.

The border style dictionary controls the width and dash pattern of the main line segment.
