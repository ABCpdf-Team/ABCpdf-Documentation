# EntryFOV Property

## Notes

Represents the "FOV" entry of the projection dictionary object.

It is defined as part of the PDF 1.0 specification.

It contains a double representing a PDF numeric object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 305, page 524.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 316, page 655.

The FOV entry gives the field of view angle in degrees for perspective projection. Larger values produce a wider field of view and a more pronounced perspective effect.
