# MediaOffsetFrameElement Class

This class represents the media offset frame dictionary. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 287, page 501.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=509)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 298, page 628.](https://www.iso.org/standard/63534.html)

A frame offset dictionary specifies a media position as a frame number. The F entry holds the zero-based frame index within the media clip. Frame offsets are used when the media format is frame-based, such as video.
