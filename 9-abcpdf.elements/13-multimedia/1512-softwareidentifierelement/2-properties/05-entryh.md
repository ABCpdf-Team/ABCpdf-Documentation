# EntryH Property

## Notes

Represents the "H" entry of the software identifier dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an array which contains integers, representing PDF numeric objects.

Items in this array should have a minimum value of 0.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 292, page 504.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 303, page 631.

The H entry holds the maximum acceptable version as an array of non-negative integers, in the same format as L.
