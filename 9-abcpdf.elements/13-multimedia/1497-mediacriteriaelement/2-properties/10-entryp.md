# EntryP Property

## Notes

Represents the "P" entry of the media criteria dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an array which contains strings, representing PDF name objects.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 268, page 490.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 279, page 614.

The P entry holds an array of language tag strings. The rendition is accepted only if the system language matches one of the listed language tags.
