# EntryD Property

## Notes

Represents the "D" entry of the media criteria dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an Element.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 268, page 490.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 279, page 614.

The D entry references a minimum bit depth dictionary specifying the minimum colour depth required for this rendition to be selected.
