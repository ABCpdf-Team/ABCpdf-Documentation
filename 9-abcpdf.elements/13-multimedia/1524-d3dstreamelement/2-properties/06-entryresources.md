# EntryResources Property

## Notes

Represents the "Resources" entry of the 3d stream dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a NameTreeNodeElement containing Elements.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 300, page 516.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.35, page 56.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 311, page 645.

The Resources entry holds a resources dictionary for assets referenced by the 3D stream, such as texture images and auxiliary data files needed by the model.
