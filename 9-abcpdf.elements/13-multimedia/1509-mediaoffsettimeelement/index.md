# MediaOffsetTimeElement Class

This class represents the media offset time dictionary. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 286, page 501.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=509)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 297, page 627.](https://www.iso.org/standard/63534.html)

A time offset dictionary specifies a media position as a time value. The T entry holds a timespan dictionary giving the offset time. Time offsets are the most common way to specify clip section boundaries.
