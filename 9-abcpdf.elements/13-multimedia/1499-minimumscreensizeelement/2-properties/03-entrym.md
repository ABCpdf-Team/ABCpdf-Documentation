# EntryM Property

## Notes

Represents the "M" entry of the minimum screen size dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an integer representing a PDF numeric object.

The PDF specification states that this item assumes a value of 0 if no value has been provided.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 270, page 491.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 281, page 615.

The M entry specifies the monitor configuration to which this minimum size criterion applies: 0 for all monitors, 1 for the largest contributing monitor, and 2 for the smallest.
