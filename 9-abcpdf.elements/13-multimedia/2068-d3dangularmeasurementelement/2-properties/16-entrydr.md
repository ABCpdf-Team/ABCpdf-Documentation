# EntryDR Property

## Notes

Represents the "DR" entry of the 3d angular dimension measurement object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a bool representing a PDF boolean object.

The PDF specification states that this item assumes a value of true if no value has been provided.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.39d, page 68.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 329, page 690.

The DR entry holds the display radius for the arc used to illustrate the angle. A larger radius draws the arc farther from the vertex for visual clarity.
