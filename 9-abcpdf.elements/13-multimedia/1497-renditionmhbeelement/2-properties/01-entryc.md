# EntryC Property

## Notes

Represents the "C" entry of the rendition mh/be dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a MediaCriteriaElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 267, page 489.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 278, page 613.

The C entry references a media criteria dictionary specifying the environmental conditions required for this rendition to be selected. All criteria specified must be satisfied.
