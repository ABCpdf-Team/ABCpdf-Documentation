# EntryS Property

## Notes

Represents the "S" entry of the 3d comment note object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a ProjectionAnnotationElement.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.39f, page 74.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 331, page 695.

The S entry holds a scale factor applied to dimensional values associated with the note.
