# EntryP Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`MediaPermissionsElement`](../../1502-mediapermissionselement/index.md) | null | No | Represents the "P" entry of the media clip data dictionary object. |

## Notes

Represents the "P" entry of the media clip data dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a [MediaPermissionsElement](../../1502-mediapermissionselement/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 274, page 492.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=500)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 285, page 617.](https://www.iso.org/standard/63534.html)

The P entry references a media permissions dictionary specifying restrictions on how the media data may be accessed, such as whether temporary files may be created.
