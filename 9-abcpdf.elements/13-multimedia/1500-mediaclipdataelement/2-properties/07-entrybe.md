# EntryBE Property

## Notes

Represents the "BE" entry of the media clip data dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an Element.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 274, page 493.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 285, page 617.

The BE entry references a best-effort clip data parameter dictionary. Parameters here are applied when possible but do not block playback if unsatisfied.
