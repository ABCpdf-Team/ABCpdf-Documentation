# D3DLightingSchemeElement Class

This class represents the 3D lighting scheme dictionary. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 309, page 530.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=538)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 320, page 662.](https://www.iso.org/standard/63534.html)

A 3D lighting scheme dictionary specifies the lighting environment applied to a 3D model. Lighting schemes control the overall illumination style, from white lighting to coloured lights to ambient-only lighting.

The named scheme selects a predefined lighting configuration. Authors can choose from standard schemes such as Artwork, White, Day, Night, Hard, Primary, Blue, Red, and Cube, each providing a different visual mood for the model.
