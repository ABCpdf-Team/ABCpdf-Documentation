# EntryN1 Property

## Notes

Represents the "N1" entry of the 3d linear dimension measurement object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a string representing a PDF string object.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.39b, page 63.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 327, page 684.

The N1 entry holds a three-element array giving the surface normal at the first anchor point, used to orient the measurement leader line perpendicular to the model surface at that point.
