# EntryTS Property

## Notes

Represents the "TS" entry of the 3d linear dimension measurement object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a double representing a PDF numeric object.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.39b, page 63.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 327, page 685.

The TS entry holds the formatted measurement text string as displayed in the annotation, including the numeric value and optional unit suffix.
