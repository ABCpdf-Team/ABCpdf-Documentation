# EntrySP Property

## Notes

Represents the "SP" entry of the media rendition dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains a MediaScreenParametersElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 271, page 491.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 282, page 616.

The SP entry references the media screen parameters dictionary that controls the display window: its size policy, position, background colour, opacity, and monitor selection.
