# EntryP Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`MediaPlayParametersElement`](../../1504-mediaplayparameterselement/index.md) | null | No | Represents the "P" entry of the media rendition dictionary object. |

## Notes

Represents the "P" entry of the media rendition dictionary object.

It is defined as part of the PDF 1.0 specification.

It contains a [MediaPlayParametersElement](../../1504-mediaplayparameterselement/index.md).

For definitive details see:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 271, page 491.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=499)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 282, page 616.](https://www.iso.org/standard/63534.html)

The P entry references the media play parameters dictionary that controls playback behaviour such as volume, repeat count, duration, and whether player controls are displayed.
