# D3DRadialMeasurementElement Class

This class represents the 3D radial dimension measurement. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 330, page 692.](https://www.iso.org/standard/63534.html)

[Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.39e, page 71.](http://www.adobe.com/content/dam/Adobe/en/devnet/acrobat/pdfs/adobe_supplement_iso32000.pdf#page=71)

A 3D radial measurement dictionary defines a measurement of the radius or diameter of a circular feature in a 3D model.

The AP, A1, A2, N2, TP, TX, TY, TS, C, V, U, P, UT, and S entries have the same meanings as in other measurement types. The A3 and A4 entries provide additional anchor points used to define the circle geometry.

The EL entry specifies the ellipse parameters when the circular feature appears as an ellipse from the measurement viewpoint. The SC entry specifies the scale centre. The R entry holds the radius value.
