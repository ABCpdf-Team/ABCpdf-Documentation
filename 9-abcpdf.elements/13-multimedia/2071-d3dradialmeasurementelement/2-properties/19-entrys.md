# EntryS Property

## Notes

Represents the "S" entry of the 3d radial dimension measurement object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a ProjectionAnnotationElement.

For definitive details see:.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 9.39e, page 71.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 330, page 693.

The S entry holds the display scale factor.
