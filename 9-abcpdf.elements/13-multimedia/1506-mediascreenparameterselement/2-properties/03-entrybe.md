# EntryBE Property

## Notes

Represents the "BE" entry of the media screen parameters dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an Element.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 282, page 498.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 293, page 624.

The BE entry references a best-effort screen parameters dictionary with display settings applied when possible but not required for playback to proceed.
