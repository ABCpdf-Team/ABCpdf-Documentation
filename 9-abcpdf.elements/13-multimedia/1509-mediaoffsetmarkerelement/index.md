# MediaOffsetMarkerElement Class

This class represents the media offset marker dictionary. This is definitively detailed in:.

[The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 288, page 501.](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf#page=509)

[The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 299, page 628.](https://www.iso.org/standard/63534.html)

A marker offset dictionary specifies a media position using a named marker embedded in the media file. The M entry holds the marker name as a byte string. Named markers allow clip sections to be tied to content-defined points rather than to fixed time or frame numbers.
