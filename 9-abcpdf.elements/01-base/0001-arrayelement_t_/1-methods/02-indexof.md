# IndexOf Function

Determines the index of a specific [Element](../../1086-element/index.md).

## Syntax

```csharp
int IndexOf(T value)
```

## Params

| Name | Description |
| :---: | --- |
| value | The [Element](../../1086-element/index.md) to locate in the Collection |
| return | If found, the index of value, otherwise -1. |
