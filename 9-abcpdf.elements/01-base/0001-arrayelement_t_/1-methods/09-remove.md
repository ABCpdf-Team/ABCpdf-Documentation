# Remove Function

Removes an [Element](../../1086-element/index.md) from the array.

## Syntax

```csharp
bool Remove(T value)
```

## Params

| Name | Description |
| :---: | --- |
| value | The [Element](../../1086-element/index.md) to remove. |
| return | True if the [Element](../../1086-element/index.md) is removed, otherwise false. |

## Notes

Removes an [Element](../../1086-element/index.md) from the array.

When an [Element](../../1086-element/index.md) is removed, the items that follow the removed item move up to occupy the vacated spot.
