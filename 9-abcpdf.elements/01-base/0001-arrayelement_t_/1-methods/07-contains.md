# Contains Function

Determines whether the array contains a specific [Element](../../1086-element/index.md).

## Syntax

```csharp
bool Contains(T value)
```

## Params

| Name | Description |
| :---: | --- |
| value | The [Element](../../1086-element/index.md) to locate. |
| return | True if the object is found, otherwise false. |

## Notes
