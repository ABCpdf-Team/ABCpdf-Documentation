# SetRect Function

Set the contents of this [RectangleElement](../index.md) using an XRect.

## Syntax

```csharp
XRect SetRect(XRect rect)
```

## Params

| Name | Description |
| :---: | --- |
| rect | The XRect containing values to be inserted into this [RectangleElement](../index.md) |
| return | The XRect that was passed in. |

## Notes
