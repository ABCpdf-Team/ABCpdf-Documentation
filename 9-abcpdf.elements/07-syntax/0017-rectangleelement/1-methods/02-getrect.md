# GetRect Function

Get the contents of this [RectangleElement](../index.md) as an XRect.

## Syntax

```csharp
XRect GetRect()
```

## Params

| Name | Description |
| :---: | --- |
| return | A new XRect with values corresponding to the contents of this [RectangleElement](../index.md). |

## Notes

Get the contents of this [RectangleElement](../index.md) as an XRect.
