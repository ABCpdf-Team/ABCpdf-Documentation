# EntryS Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | This property represents the "S" entry of the link structure attributes object. |

## Notes

This property represents the "S" entry of the link structure attributes object.

The S entry names the link attribute type. A value of URL indicates a URI-based link; a value of Page indicates a link to a specific page. The type determines how the other entries in the dictionary are interpreted.
