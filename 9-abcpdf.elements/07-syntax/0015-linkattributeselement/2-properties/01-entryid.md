# EntryID Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string` | null | No | This property represents the "ID" entry of the link structure attributes object. |

## Notes

This property represents the "ID" entry of the link structure attributes object.

The ID entry holds the URI string associated with this link attribute. For URL-type link attributes, this is the address of the web resource from which the associated page content was captured.
