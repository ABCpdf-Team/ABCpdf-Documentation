# EntryXFAResources Property

## Notes

Represents the "XFAResources" entry of the name dictionary object.

It is an optional entry defined as part of the PDF 1.7 Extension Level 3 specification.

It contains a NameTreeNodeElement containing StreamElements.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 31, page 80.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 3.28, page 23.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 32, page 108.

The XFAResources entry references a name tree mapping resource names to XFA resource streams. This supports XFA-based form documents that reference external resources by name.
