# EntryAlternatePresentations Property

## Notes

Represents the "AlternatePresentations" entry of the name dictionary object.

It is an optional entry defined as part of the PDF 1.4 specification. It was deprecated in PDF 2.0.

It contains a NameTreeNodeElement containing SlideshowElements.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 31, page 81.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 3.28, page 23.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 32, page 109.

The AlternatePresentations entry references a name tree mapping presentation names to alternate presentation dictionaries. Alternate presentations define slide-show or multimedia presentations that can be activated by name.
