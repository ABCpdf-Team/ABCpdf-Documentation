# EntryRenditions Property

## Notes

Represents the "Renditions" entry of the name dictionary object.

It is an optional entry defined as part of the PDF 1.5 specification.

It contains a NameTreeNodeElement containing RenditionElements.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 31, page 81.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 3.28, page 23.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 32, page 109.

The Renditions entry references a name tree mapping rendition names to rendition objects. Named renditions can be referenced by media play actions, allowing the same rendition to be activated from multiple locations.
