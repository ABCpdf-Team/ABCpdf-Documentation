# EntryDesc Property

## Notes

Represents the "Desc" entry of the full file specification dictionary object.

It is an optional entry defined as part of the PDF 1.6 specification.

It contains a string representing a PDF string object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 44, page 103.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 3.41, page 26.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 43, page 134.

The Desc entry holds a human-readable Unicode string describing the embedded file. Viewers typically display this description in the attachments panel alongside the file name.
