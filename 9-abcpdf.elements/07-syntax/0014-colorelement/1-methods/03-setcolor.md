# SetColor Function

Set the contents of this [ColorElement](../index.md) using an XColor.

## Syntax

```csharp
XColor SetColor(XColor color)
```

## Params

| Name | Description |
| :---: | --- |
| color | The XColor containing values to be inserted into this [ColorElement](../index.md) |
| return | The XColor that was passed in. |

## Notes
