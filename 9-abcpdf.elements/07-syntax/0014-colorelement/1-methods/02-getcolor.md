# GetColor Function

Get the contents of this [ColorElement](../index.md) as an XColor.

## Syntax

```csharp
XColor GetColor()
```

## Params

| Name | Description |
| :---: | --- |
| return | A new XColor with values corresponding to the contents of this [ColorElement](../index.md). |

## Notes

Get the contents of this [ColorElement](../index.md) as an XColor.
