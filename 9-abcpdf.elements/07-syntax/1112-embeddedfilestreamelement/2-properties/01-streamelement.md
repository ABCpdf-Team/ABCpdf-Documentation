# StreamElement Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| [`StreamElement`](../../1028-streamelement/index.md) | null | Yes | The [StreamElement](../../1028-streamelement/index.md) associated with this class. |

## Notes

The [StreamElement](../../1028-streamelement/index.md) associated with this class.

The stream body contains the embedded file data, compressed and filtered according to the Filter and DecodeParms entries in the stream dictionary. After decoding, the stream bytes are identical to the original file contents.
