# EntryParams Property

## Notes

Represents the "Params" entry of the embedded file stream dictionary object.

It is an optional entry defined as part of the PDF 1.0 specification.

It contains an EmbeddedFileParameterElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 45, page 104.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 44, page 136.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 244, page 460.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 247, page 558.

The Params entry references an embedded file parameter dictionary that holds metadata about the embedded file: its uncompressed size, creation and modification dates, and an MD5 checksum.
