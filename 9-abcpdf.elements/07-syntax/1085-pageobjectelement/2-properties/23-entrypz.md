# EntryPZ Property

## Notes

Represents the "PZ" entry of the page object object.

It is an optional entry defined as part of the PDF 1.3 specification.

It contains a double representing a PDF numeric object.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 30, page 79.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 3.27, page 23.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 31, page 105.

The PZ entry gives the preferred zoom factor for displaying the page. It is used by the web capture mechanism to record the zoom level at which the captured page was intended to be viewed.
