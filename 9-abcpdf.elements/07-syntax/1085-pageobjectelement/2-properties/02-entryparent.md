# EntryParent Property

## Notes

Represents the "Parent" entry of the page object object.

It is a required entry defined as part of the PDF 1.0 specification.

It contains a PageTreeNodeElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 30, page 77.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 3.27, page 23.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 31, page 103.

The Parent entry references the page tree node that contains this page in its Kids array. Every page must have a Parent entry pointing to a valid page tree node.
