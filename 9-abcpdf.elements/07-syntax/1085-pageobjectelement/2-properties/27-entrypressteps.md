# EntryPresSteps Property

## Notes

Represents the "PresSteps" entry of the page object object.

It is an optional entry defined as part of the PDF 1.5 specification.

It contains a NavigationNodeElement.

For definitive details see:.

The ISO PDF Specification, ISO 32000-1:2008 PDF 1.7; Table: 30, page 79.

Adobe Supplement to the ISO 32000, BaseVersion: 1.7, ExtensionLevel: 3; Table: 3.27, page 23.

The ISO PDF Specification, ISO 32000-2:2017 PDF 2.0; Table: 31, page 106.

The PresSteps entry references a presentation steps dictionary for sub-page navigation. It allows a single page to present multiple steps of content sequentially, similar to slide builds in presentation software.
