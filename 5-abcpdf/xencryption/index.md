# XEncryption Class

Represents the current encryption settings.

By default encryption is not applied unless you explicitly specify it using the Type property.

```
System.Object
    WebSupergoo.ABCpdf14.XEncryption

Implements: IDisposable
```

## Methods

| Method | Description |
| --- | --- |
| ⚠ [SetCryptMethods](1-methods/setcryptmethods.md) | Sets the crypt methods for encryption levels of type 4 or above. |
| [ToString](1-methods/tostring.md) | Returns a string representation of the object. |
