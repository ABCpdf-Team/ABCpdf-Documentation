# CompressionLevel Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `int?` | null | No | The compression level to apply when performing lossless compression. |

## Notes

The compression level to apply when performing lossless compression.

The value is a percentage with higher numbers indicating higher levels of compression.

Higher levels of compression take longer than lower ones.

A value of null (the default) indicates a default level of compression.
