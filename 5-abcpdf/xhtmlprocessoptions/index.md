# XHtmlProcessOptions Class

Represents the options for new HTML worker processes.

```
System.Object
    WebSupergoo.ABCpdf14.XHtmlProcessOptions
```

## Methods

| Method | Description |
| --- | --- |
| [SkipEngineDependencyCheck](1-methods/skipenginedependencycheck.md) | Skip the check of engine-dependent options that are set since last HTML import. |
| [StartPool](1-methods/startpool.md) | Start the process pool for the HTML Engine. |

## Properties

| Property | Description |
| --- | --- |
| [MaxProcesses](2-properties/1-maxprocesses.md) | The maximum number of processes for the HTML Engine. |
| [PoolHasStarted](2-properties/1-poolhasstarted.md) | Whether the process pool for the HTML Engine has started. |
| [ProcessCount](2-properties/1-processcount.md) | The number of existing processes for the HTML Engine. |
| [Domain](2-properties/domain.md) | The domain or server containing the user. |
| [IdleTimeout](2-properties/idletimeout.md) | The maximum time a process can be idle before being terminated (ms). |
| [LoadUserProfile](2-properties/loaduserprofile.md) | Whether to load the user profile. |
| [Password](2-properties/password.md) | The password for the user. |
| [RetryCount](2-properties/retrycount.md) | The number of times an operation should be retried if there is a problem with the process. |
| [UserName](2-properties/username.md) | The user name. |
