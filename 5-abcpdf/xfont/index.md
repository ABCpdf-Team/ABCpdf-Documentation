# XFont Class

Provides information about the fonts available to ABCpdf.

```
System.Object
    WebSupergoo.ABCpdf14.XFont
```

## Methods

| Method | Description |
| --- | --- |
| Ⓢ [FindAll](1-methods/findall.md) | Find all the fonts currently installed on the system. |
| Ⓢ [FindFamily](1-methods/findfamily.md) | Find all the fonts belonging to a particular family. |
| Ⓢ [FindFamilyNames](1-methods/findfamilynames.md) | Find the names of all font families. |
| Ⓢ [FindByName](1-methods/findbyname.md) | Find all the fonts with a given name. |
| Ⓢ [FindByStyle](1-methods/findbystyle.md) | Find a font from a specific family, with a given style. |
| [TextWidth](1-methods/textwidth.md) | Calculate the width of a string of text. |
| Ⓢ [Load](1-methods/load.md) | Loads a font from file. |
| [Unload](1-methods/unload.md) | Unloads a font so that it is no longer available. |

## Properties

| Property | Description |
| --- | --- |
| [IsPrivate](2-properties/isprivate.md) | Whether the font is in a font store. |
| [IsDisposed](2-properties/isdisposed.md) | Whether the font has been disposed of if it is a private font. |
| [FamilyName](2-properties/familyname.md) | The name of the family to which the font belongs. |
| [FixedPitch](2-properties/fixedpitch.md) | Whether the font is in a fixed pitch style. |
| [Italic](2-properties/italic.md) | Whether the font is in an italic style. |
| [Name](2-properties/name.md) | The complete human readable name of the font. |
| [Names](2-properties/names.md) | The complete set of names by which this font is known. |
| [PostScriptName](2-properties/postscriptname.md) | The name the font will be known by on a PostScript printer. |
| [Script](2-properties/script.md) | Whether the font is in a script style. |
| [Serif](2-properties/serif.md) | Whether the font is in a serif style. |
| [Symbolic](2-properties/symbolic.md) | Whether the font contains symbolic rather than Unicode glyphs. |
| [Weight](2-properties/weight.md) | The weight of the font. |
| [Baseline](2-properties/baseline.md) | The baseline of the font in thousandths of a unit. |
| [Embeddable](2-properties/embeddable.md) | Whether the licensing rights in the font indicate that it may be embedded. |
| [Paths](2-properties/paths.md) | The paths to the files that contain the font definition. |
| [Widths](2-properties/widths.md) | The widths of the characters in the font. |
