# Paths Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `string[]` | n/a | Yes | The paths to the files that contain the font definition. |

## Notes

The paths to the files that contain the font definition.

Most fonts are contained in only one font file, however PostScript fonts can consist of both a PFM and PFB file. If there is no font file this property may be null.
