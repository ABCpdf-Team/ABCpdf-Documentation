# Embeddable Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `bool` | n/a | Yes | Whether the licensing rights in the font indicate that it may be embedded. |

## Notes

Whether the licensing rights in the font indicate that it may be embedded.

TrueType and OpenType fonts contain licensing rights flags. If this property is true it indicates that either the editable embedding or bitmap embedding flags are true.
