XTagging Class    

A class that allows control over PDF tagging for document accessibility.

System.Object

Method
 Description
MakeTag Make a tag with a unique ID.
OpenClose Opens the tag then closes it.
CloseOpen Closes the current tag then opens a new one.
Open Opens a sequence of tags.
Close Closes a sequence of tags.
GetStructure Gets the current Structure for the document.
Commit Commit any changes that may be required as a result of moving between two pages.
WriteRaw Writes a raw tag to the content stream.
AddFocus Assign a tag to a particular area of the current page.
