# OpenClose Function

Opens the tag then closes it.

## Syntax

[C#]

```csharp
<a href="../default.htm">Tag</a> OpenClose(<a href="../default.htm">Tag</a> tag)<a href="../default.htm">Tag</a> OpenClose(string type)
```

## Params

| **Name** | **Description** |
| --- | --- |
| tag | The tag to be opened and closed. |
| type | The type of tag to be opened and closed. |
| return | The tag that was opened and closed. |
