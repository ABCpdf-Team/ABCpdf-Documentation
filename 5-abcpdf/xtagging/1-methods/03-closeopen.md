# CloseOpen Function

Closes the current tag then opens a new one.

## Syntax

[C#]

```csharp
<a href="../default.htm">Tag</a> CloseOpen(<a href="../default.htm">Tag</a> tag)<a href="../default.htm">Tag</a> CloseOpen(string type)
```

## Params

| **Name** | **Description** |
| --- | --- |
| tag | The tag to be opened. |
| type | The type of tag to be opened and closed. |
| return | The tag that was opened. |
