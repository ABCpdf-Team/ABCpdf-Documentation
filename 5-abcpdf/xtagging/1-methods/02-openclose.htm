OpenClose Function    

Opens the tag then closes it.

 

    

Syntax		  

[C#]
Tag OpenClose(Tag tag)
Tag OpenClose(string type)

 

    

Params		  
Name Description
tag The tag to be opened and closed.
type The type of tag to be opened and closed.
return The tag that was opened and closed.

 

    

Notes		  
Opens the tag then closes it.
