# Focii Property

| Type | Default Value | Read Only | Description |
| --- | --- | --- | --- |
| `List<`[`Focus`](../../xtagging.focus/index.md)`>` | null | Yes | The focii to use for area based tagging. |

## Notes

The focii to use for area based tagging.

Focii can be added directly to this list or indirectly by using the [AddFocus](../1-methods/08-addfocus.md) method.

This property is read only, but the list it returns can be modified.
