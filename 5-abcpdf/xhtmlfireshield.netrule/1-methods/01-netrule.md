# NetRule Function

Network access rule constructor.

## Syntax

*C#*

[`NetRule`](../index.md)`()`  
[`NetRule`](../index.md)`(IPAddress lo, IPAddress hi, AccessType access)`

## Params

| Name | Description |
| :---: | --- |
| lo | The low address in a range specifying IP addresses to control. See the [Lo](../2-properties/01-lo.md) property. |
| hi | The high address in a range specifying IP addresses to control. See the [Hi](../2-properties/02-hi.md) property. |
| access | The type of control to exercise over the resource. See the [Access](../2-properties/03-access.md) property. |

## Notes

Network access rule constructor.
