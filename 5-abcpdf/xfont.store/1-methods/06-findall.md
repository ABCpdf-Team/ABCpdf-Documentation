# FindAll Function

Returns all fonts held in this font store.

## Syntax

*C#*

[`XFont`](../../xfont/index.md)`[] FindAll()`

## Params

| Name | Description |
| :---: | --- |
| return | An array of [XFont](../../xfont/index.md) objects representing the complete set of fonts in the store. |

## Notes

Returns all fonts held in this font store.

There are also [XFont.FindFamily](../../xfont/1-methods/findfamily.md), [XFont.FindFamilyNames](../../xfont/1-methods/findfamilynames.md), [XFont.FindByName](../../xfont/1-methods/findbyname.md) and [XFont.FindByStyle](../../xfont/1-methods/findbystyle.md) function overloads which allow you to include a font store when searching for fonts.
