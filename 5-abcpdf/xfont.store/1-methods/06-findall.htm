FindAll Function    

Returns all fonts held in this font store.

 

    

Syntax		  

[C#]
XFont[] FindAll()

 

    

Params		  
Name Description
return An array of XFont objects representing the complete set of fonts in the store.

 

    

Notes		  

Returns all fonts held in this font store.

There are also XFont.FindFamily, XFont.FindFamilyNames, XFont.FindByName and XFont.FindByStyle function overloads which allow you to include a font store when searching for fonts.

 

    

Example		  
None.
