# Store Function

## Syntax

[C#]

```csharp
<a href="../default.htm">Store</a>()<a href="../default.htm">Store</a>(<a href="../default.htm">Store</a> store)
```

## Params

| **Name** | **Description** |
| --- | --- |
| store | An original font store to copy. |

## Notes

Creates a new XFont.Store instance.

If a store is provided, the newly created store establishes contact with the source font store.

For more information on how private font stores interact when they make contact, see the remarks in the [class overview](default.md).
