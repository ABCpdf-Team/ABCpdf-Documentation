# AddButton Function

Add button field.

## Syntax

```csharp
Field AddButton(XRect rect, string name, string caption)
```

## Params

| Name | Description |
| :---: | --- |
| rect | Rectangle of the form field |
| name | Name of the form field |
| caption | Caption of the button |
| return | Form field object |

## Notes

Add a button field.
