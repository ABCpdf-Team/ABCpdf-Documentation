# AddButton Function

Add button field.

## Syntax

[C#]

```csharp
Field AddButton(XRect rect, string name, string inCaption)
```

## Params

| **Name** | **Description** |
| --- | --- |
| rect | Rectangle of the form field |
| name | Name of the form field |
| inCaption | Caption of the button |
| return | Form field object |

## Notes

Add a button field.
