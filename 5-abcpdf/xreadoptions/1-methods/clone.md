# Clone Function

Creates a deep copy of the current XReadOptions.

## Syntax

*C#*

[`XReadOptions`](../index.md)` Clone()`

## Params

| Name | Description |
| :---: | --- |
| return | The newly created copy. |

## Notes

This function creates a new XReadOptions that is a copy of this instance.

The copy is a deep copy, so changes made to the copy do not affect the original.
