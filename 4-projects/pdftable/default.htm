PDFTable Example Project    

 

    

Project		  

The project detailed here shows how to create PDF tables based on programmatic control.

There is a certain amount of overlap between this project, the WPFTable and the HTMLTables Example projects. All do similar things in slightly different ways.

This project is based on programmatic control rather than HTML style input or WPF.

You can read more about how to use this project in the Small Table Example and Large Table Example sections of this document.

The PDFTable class allows you to define the columns and then move from cell to cell adding text, styled text, images or even nested tables. You can set alignment and cell padding, add fills and frames to cells, rows and columns, and rotate content.

Tables can flow across multiple pages with the header rows repeated at the top of each page. The examples include a small table with rotated text, a large table of text and an invoice built from XML data.
