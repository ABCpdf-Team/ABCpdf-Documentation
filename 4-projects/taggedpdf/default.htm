TaggedPDF Example Project    

 

    

Project		  

PDF documents can contain tags to indicate semantic structure.

This example shows how to create tagged documents using a low level approach.

It takes content specified as XML and converts it to content and associated tags.

The simple example creates a tagged PDF directly in code, adding a paragraph of text, an image and a heading. The XML example reads a simple HTML-like format containing headings, paragraphs, styled text and images.

In each case the page content is created together with a matching structure tree, so the document contains its logical structure for accessibility, reflow and text extraction.
