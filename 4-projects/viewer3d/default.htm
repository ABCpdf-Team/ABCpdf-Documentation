Viewer3D Example Project    

 

    

Project		  

The Viewer3D project contains a control for interactive viewing of 3D objects in PDF documents.

It supports the PDF 3D standards - U3D and PRC. So by extracting this information from your documents you can then view your 3D models.

This project includes the 3D control inside an application wrapper so you can easily see what it can do.

The Render3DControl is a WPF control which displays 3D scenes using OpenGL. It supports different lighting schemes and anti-aliasing and allows you to switch between the camera views stored in the model.

The project also shows how to find the 3D annotations in a PDF and extract the U3D or PRC data and view definitions. The viewer can open 3D files directly, capture a scene to an image and export a scene to PRC.
